🧠 AuDHD 执行功能减压舱 (AuDHD Decompression Chamber)
“认知能量追踪 · 守护大脑续航”

📖 项目简介
AuDHD 执行功能减压舱 是一款专为自闭症与注意缺陷多动障碍共病（AuDHD）及神经多样性群体公益定制的轻量级 Web App。本项目基于前沿神经医学研究设计，充当使用者的“外置前额叶”。通过将模糊的生活任务原子化、人类的社交暗示代码化，系统帮助用户有效跨越执行功能瘫痪，并通过动态能量追踪，主动干预并预防灾难性的神经能量枯竭（系统保护性关机）。
✨ 核心功能模块

    🎯 任务拆解器 (Task Breakdown)：将引发焦虑的模糊任务（如写邮件、办业务）一键拆解为 5 个无需情绪参与的纯物理微小步骤，打破“任务启动障碍”。
    🔍 社交解码器 (Social Decoder)：针对存在述情障碍的群体设计。将职场与人际交往中的“高频黑话”转化为理性的百分比概率与“无耗能回复剧本”，强行切断社交反刍。
    ⚖️ 多巴胺与秩序天平 (Energy Tracker)：全局动态追踪前额叶认知电量。整合临床验证的代偿干预手段（如 Focusmate 虚拟替身陪伴、物理自我刺激、听觉隔离等），在能量触底前触发系统保护性关机警告。

🛠 设计与技术亮点

    感官友好设计 (Sensory-Friendly UI)：摒弃高饱和度色彩与弹窗，支持防视觉过载的“暗黑模式”与低对比度、带有积极心理暗示（鼠尾草绿/暖米色）的“护眼白天模式”。
    去污名化架构 (De-stigmatization)：全站告别缺陷视角词汇，将传统的病理词汇重构为中性的技术语言，降低患者羞耻感。

愿景：你不是出现了功能故障，你只是需要适配你神经系统的专属运行环境。
